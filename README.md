# Harmonic_Eigenspace_Dataset
Dataset for "Harmonic Eigenspace: A Web-based Application for Navigating and Composing Microtonal Harmony." Contains listening test responses from 31 participants rating 20 isolated 53-TET chords (dissonance) and 10 chord progressions (coherence, musicality, dissonance, novelty), audio stimuli, and jsPsych experiment code.
